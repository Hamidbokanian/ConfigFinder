# Config Finder — راهنمای ساخت APK

سازنده: حمید بوکانیان — 09378976737

برنامه‌ای که برای **v2ray**، **Outline** و **NPV Tunnel** کانفیگ سالم با پینگ حداکثر ۱۵۰ms پیدا می‌کنه.

## ساخت APK (روش پیشنهادی، بدون نصب چیزی؛ حدود ۵ دقیقه)
1. توی github.com یه مخزن (repository) جدید بساز.
2. همه‌ی فایل‌های این پروژه رو داخلش آپلود کن (پوشه‌ی `.github` هم باید باشه).
   اگه آپلود پوشه‌ی `.github` رو قبول نکرد: Add file → Create new file، اسمش رو `.github/workflows/build-apk.yml` بذار و محتوای فایل رو paste کن.
3. تب **Actions** → **Build APK** → **Run workflow**.
4. وقتی سبز شد، وارد اجرا شو و پایین صفحه از بخش **Artifacts** فایل `ConfigFinder-APK` رو دانلود کن (داخل zip، فایل `app-debug.apk` هست).
5. APK رو نصب کن (اجازه‌ی نصب از منبع ناشناس لازمه).

اگه بیلد خطا داد، متن خطا (قسمت قرمز لاگ) رو برام بفرست تا درستش کنم.

## روش دوم: Android Studio
پوشه رو باز کن → Build → Build APK(s). فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## طرز کار (دو مرحله)
- لیست‌ها از منابع عمومی GitHub گرفته میشه (اولویت با لیست‌های `top100` و `tested`).
- **مرحله ۱:** پینگ اتصال (TCP) از خود گوشی؛ فقط سرورهای زیر سقف پینگ (پیش‌فرض ۱۵۰ms) می‌مونن. برای TLS/Reality هندشیک TLS هم چک میشه.
- **مرحله ۲ (تست واقعی):** هر کانفیگ داخل هسته‌ی Xray اجرا میشه و یه درخواست HTTPS واقعی از داخلش رد میشه (`gstatic.com/generate_204`). فقط اون‌هایی که واقعاً کار کردن می‌مونن و بر اساس پینگ واقعی مرتب میشن.
- برای Outline فقط کانفیگ Shadowsocks با رمزنگاری AEAD و بدون پلاگین نشون داده میشه.
- هسته‌ی Xray (libv2ray.aar از پروژه‌ی 2dust/AndroidLibXrayLite، مجوز LGPL-3.0) موقع بیلد خودکار دانلود میشه.
- دکمه‌ی «کپی و باز کردن برنامه» کانفیگ رو کپی می‌کنه و برنامه رو باز می‌کنه؛ داخلش «Import from clipboard» رو بزن.

## حالت VPN (خود برنامه وصل میشه)
- **اتصال خودکار با VPN:** اسکن می‌کنه، بهترین کانفیگ تست‌شده رو انتخاب می‌کنه و وصل میشه. اگه ترافیک رد نشد خودش تا ۴ کانفیگ بعدی رو امتحان می‌کنه.
- یا روی کارت نتیجه «اتصال با VPN خود برنامه» رو بزن.
- اولین بار اندروید اجازه‌ی VPN می‌پرسه؛ تایید کن. برای قطع کردن «قطع اتصال VPN» رو بزن.
- پشت صحنه: اندروید یه تونل (TUN) می‌سازه و هسته‌ی Xray مستقیم ازش می‌خونه. خود برنامه از تونل مستثناست تا ترافیک هسته به خودش برنگرده. DNS هم با DoH از داخل پروکسی انجام میشه.
- ترافیک IPv6 وارد تونل نمیشه و همه‌ی برنامه‌ها از VPN رد میشن (فعلاً تقسیم‌بندی برنامه‌ها نداریم).

## محدودیت‌ها (صادقانه)
- پینگ واقعی یه درخواست کامل HTTPS از داخل پروکسی‌ئه (چند رفت‌وبرگشت)، پس معمولاً چند برابر پینگ TCP هست. سقف پیش‌فرضش ۱۵۰۰ms هست و در «تنظیمات» قابل تغییره.
- کانفیگ‌هایی که `allowInsecure` دارن یا ترنسپورت‌های kcp/quic دارن تست نمیشن و نشون داده نمیشن.
- قبل از اسکن VPN رو خاموش کن.
- اگه کانفیگی با پینگ ≤150 پیدا نشد، سقف پینگ رو در «تنظیمات» بالاتر ببر یا منبع اضافه کن.
